An AI/ML-based Fake News Detection System that uses Natural Language Processing (NLP) and Machine Learning to classify news articles as Real or Fake.

## 🚀 Features

- Detects fake and real news
- Uses NLP-based text processing
- TF-IDF for feature extraction
- Passive Aggressive Classifier for prediction
- Streamlit-based web interface
- Trained on the WELFake dataset

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- TF-IDF
- Passive Aggressive Classifier
- Joblib
- Streamlit

## 📊 Dataset

The project uses the WELFake dataset containing real and fake news articles.

The dataset labels are:

- `0` → Fake News
- `1` → Real News

## ⚙️ How It Works

News Article
     ↓
Text Preprocessing
     ↓
TF-IDF Vectorization
     ↓
Machine Learning Model
     ↓
Prediction
     ↓
Real / Fake
